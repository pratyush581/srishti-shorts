# Srishti Shorts v2

A private-feeling, offline-first Shorts/Reels-style video player for iPhone.

## v2 features
- Full-screen vertical swipe feed
- Tap video to pause/play
- Big play/pause and volume buttons
- Favorites
- Favorites-only mode
- Shuffle
- Loop on/off
- Manage/delete individual videos
- Delete all
- Local IndexedDB storage; videos are not uploaded to GitHub
- Offline app shell via service worker

## Install
1. Put these files at the root of a GitHub Pages repository.
2. Enable GitHub Pages from the `main` branch and `/(root)`.
3. Open the Pages URL in Safari on iPhone.
4. Share -> Add to Home Screen -> Open as Web App -> Add.
5. Open the app and use Manage -> Add videos.
6. Test in Airplane Mode before travel.

Use videos you own or have permission to use. For maximum iPhone compatibility, H.264 MP4 is a good choice.

For child-proofing, use iOS Guided Access after opening the app.
